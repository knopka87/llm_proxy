# CLAUDE.md

Полное руководство по проекту — в @AGENTS.md (карта репозитория, команды, конфигурация,
подводные камни). Держи его в актуальном состоянии при изменении структуры.

Быстрые напоминания для этой сессии:
- Актуальный код — в `api/internal/v2/`; `v1/` — legacy.
- Сборка/запуск: `go build -o server ./api/cmd/llm-proxy`, порт по умолчанию 8000.
- Обязательные секреты: `GEMINI_API_KEY`, `OPENAI_API_KEY` (бери имена из `.env.example`).
- Перед изменением LLM-моделей сверься с `docs/llm_analysis.md`.
