═══ НЕЗАВИСИМАЯ ПРОВЕРКА: ТАБЛИЧКИ/БУКВЫ/ВРЕМЯ (verify_tables) ═══
Задачи где «одинаковые буквы — одинаковое время/стоимость», подстановка символов в таблицу.

АЛГОРИТМ ПРОВЕРКИ:
1) Введите переменные для букв (или работайте через подсчёт букв).
2) Составьте уравнения по данным табличкам.
3) Найдите время/стоимость для нужной таблички и проверьте обратной подстановкой.

ПРИМЕР:
Условие: "А+Б=10, Б+В=8, А+В=12. Найти А, Б, В."
→ Из уравнений: А=(10+12-8)/2=7, Б=3, В=5. Проверка: 7+3=10 ✓, 3+5=8 ✓, 7+5=12 ✓.

ОСОБЕННОСТИ:
• Составляйте систему уравнений, если букв несколько.
• Проверяйте обратной подстановкой после нахождения ответа.
• Если табличка содержит числовые значения — проверяйте каждую строку.
