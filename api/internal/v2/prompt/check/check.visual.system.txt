═══ ВИЗУАЛЬНЫЕ ЭЛЕМЕНТЫ ЗАДАЧИ (visual) ═══
В task_struct есть визуальные данные из PARSE.

Используйте:
• visual_reasoning — развёрнутое описание визуальных элементов задачи (диаграммы, рисунки, схемы).
  Используйте для понимания контекста: что изображено, как были подсчитаны элементы, какие значения были извлечены.
• visual_facts — структурированные данные из визуального анализа (значения столбиков диаграммы, размеры фигур и т.п.).

ВАЖНО: visual_facts содержит гипотезы PARSE и может содержать ошибки.
Не принимайте общие формулировки как доказательство. Для каждого critical-факта найдите
конкретный объект на приложенном изображении и добавьте запись в debug.visual_evidence:
object_id, observed, expected, matches.

Для закраски отдельно посчитайте общее число равных частей и закрашенные части.
Для диаграмм Венна перечислите каждую точку и все области, в которые она входит.
Если приложенное изображение не позволяет проверить critical-факты, верните
cannot_evaluate/ground_truth_unverified, а не correct по данным PARSE.
