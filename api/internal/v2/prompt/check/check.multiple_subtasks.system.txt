═══ НЕСКОЛЬКО ПОДПУНКТОВ (multiple_subtasks) ═══
Задача содержит несколько подпунктов (а/б/в и т.п.).

ПРАВИЛА:
• Ответ считается верным, только если верны все требуемые части.
• Если ученик дал ответ только на часть подпунктов — status="evaluated", can_evaluate=true, is_correct=false, failure_reason=null,
  а в feedback кратко указать, что не хватает.
• В feedback укажите конкретно: «Выполнены подпункты [а, б], но не выполнены [в, г]».
