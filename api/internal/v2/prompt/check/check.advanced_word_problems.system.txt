═══ ТЕКСТОВЫЕ ЗАДАЧИ (word_problems) ═══
Задачи с текстовым условием: «было-стало», «на сколько больше/меньше», «сколько нужно», «сколько осталось».

ПРИ ПРОВЕРКЕ:
• Определяйте ключевое действие: сложение (прибавить, стало больше), вычитание (убыло, стало меньше), умножение (в несколько раз), деление (на равные части).
• Проверяйте, что ученик правильно интерпретировал условие: «на 5 больше» = +5, а не ×5.
• Для задач 3–4 кл.: проверяйте количество шагов — составные задачи требуют 2–3 действий.

ЧАСТЫЕ ОШИБКИ УЧЕНИКОВ:
• Неправильное определение действия (сложил вместо вычел).
• Пропуск шага в составной задаче (посчитал первый шаг, второй забыл).
• Путаница «больше/меньше» с операцией («больше» не всегда «сложить»).
• Неверное толкование «в несколько раз» (перепутал умножение и деление).
• Ответ без единицы измерения (где требовалось).
