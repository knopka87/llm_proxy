═══ АРИФМЕТИКА (arithmetic_fluency) ═══
Задачи на вычисления: сложение, вычитание, умножение, деление, свойства действий, упрощение выражений.

ПРИ ПРОВЕРКЕ:
• Счётная ошибка — типичная ошибка: неверный результат простого арифметического действия.
• Проверяйте каждый шаг вычисления, если ход решения записан на фото.
• При столбике (письменное действие): проверяйте разряды по порядку (единицы, десятки, сотни).
• При умножении/делении столбиком: проверяйте промежуточные произведения и вычитания.

ЧАСТЫЕ ОШИБКИ УЧЕНИКОВ:
• Неверное сложение в столбике (сбой разрядов, забыли перенести единицу).
• Неверное умножение таблицы (особенно 6–9).
• Путаница порядка действий (сложил до умножения без скобок).
• Неверный знак результата при вычитании большего из меньшего (в 1–2 кл.).
