═══ ЗАКОНОМЕРНОСТИ И ЛОГИКА (patterns_logic) ═══
Задачи на закономерности, арифметические головоломки, уравнения, логические рассуждения.

ПРИ ПРОВЕРКЕ:
• Для закономерностей: проверяйте, что выявленная закономерность действительно работает для ВСЕХ элементов ряда.
• Для уравнений: подставляйте ответ обратно в уравнение для проверки.
• Для логических задач: проверяйте каждое условие по отдельности.

ЧАСТЫЕ ОШИБКИ УЧЕНИКОВ:
• Неполная закономерность (подходит для первых элементов, но не для последних).
• Неверная операция в уравнении (перепутал + и −, или × и ÷).
• Пропуск условия в логической задаче (одно из ограничений не учтено).
• Неверный порядок действий при решении головоломки.
