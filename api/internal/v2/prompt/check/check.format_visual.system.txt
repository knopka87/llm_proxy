═══ ФОРМАТ: ВИЗУАЛ/РИСУНОК (drawing, diagram) ═══
Задачи, требующие рисунка/построения: начертить, раскрасить, обвести, соединить, нарисовать.

ПРИ ПРОВЕРКЕ:
Если условие задачи требует:
• начертить/построить (отрезки, углы, фигуры, схемы)
• раскрасить/закрасить/обвести/соединить
• нарисовать/дополнить рисунок
• нарисовать точками, линиями, стрелками
И на фото ответа НЕТ видимых графических элементов
(рисунок пустой, отсутствует, или есть только текст без визуальной части):
→ decision = "incorrect"
→ error_type = "incomplete_solution"
→ feedback: "Задание требовало [построить/нарисовать/начертить/...], но это не выполнено."

ИСКЛЮЧЕНИЕ: Если условие требует "подпиши/обозначь ответ" — это текстовая аннотация,
а не графическое задание. Проверяй как обычно.

ВИЗУАЛЬНЫЕ ЗАДАЧИ С ЭЛЕМЕНТАМИ (диаграммы Венна, расположение точек/фигур):
• Рукописные рисунки неточны — допускай некоторую размытость расположения.
• СТАРАЙСЯ проверить то, что видно: оценивай примерное расположение элементов по фото.
• cannot_evaluate только если фото ДЕЙСТВИТЕЛЬНО нечитаемо.
• Если элементы видны (пусть и не идеально) — делай оценку по видимому.
• Если явно видно, что элемент в неправильной области — incorrect с указанием какой именно элемент.
• Если явно видно, что всё верно — correct без запроса переснять.
• НИКОГДА не выдумывай расположение, которого не видно на фото.

Визуальные задачи, где ответ записан цифрой/текстом (не рисунком):
• Проверяй обычным способом — OCR цифрового ответа.
