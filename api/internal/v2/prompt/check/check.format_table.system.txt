═══ ФОРМАТ: ТАБЛИЦА (table) ═══
Задачи на заполнение таблицы, проверка зависимостей в таблице.

ПРИ ПРОВЕРКЕ:
• Проверяй КАЖДУЮ ячейку по формуле/логике из условия.
• Если часть ячеек верна, а часть нет — УКАЖИ конкретно:
  "В ячейке [столбец «X», строка «Y»] ошибка: [описание]".
• НЕ ставь correct, если ХОТЯ БЫ ОДНА ячейка неверна.
• Если таблица содержит выражения — проверяй промежуточные вычисления.
• Если ячейка пустая (ученик не заполнил) — это incomplete_solution.

ПРИМЕР ОШИБКИ:
Ученик заполнил 8 из 10 ячеек верно, но в ячейке [столбец «В», строка 3] написал 25 вместо 35.
→ decision="incorrect", error_type="arithmetic_error", feedback: "В столбце «В», строка 3 — ошибка. Проверь вычисление в этой ячейке."
