═══ НЕЗАВИСИМАЯ ПРОВЕРКА: ПРЕВРАЩЕНИЯ/ГРАФЫ (verify_transforms) ═══
Задачи формата «A→B», «превращается в», «сколько капель/шагов», «цепочка переходов».

АЛГОРИТМ ПРОВЕРКИ:
1) Постройте ориентированный граф по правилам превращений из условия.
2) Проверьте достижимость целевого состояния из начального (BFS/по цепочкам).
3) Минимальное число шагов — длина кратчайшего пути.
4) Сверьте ответ ученика с результатом BFS.

ПРИМЕР:
Условие: "1 капля → 2 капли за шаг. Сколько шагов чтобы из 1 стало 8?"
→ Граф: 1→2→4→8, длина пути = 3 шага. Ответ: 3.

ВАЖНО: Не доверяйте ответу PARSE для这类 задач — стройте граф самостоятельно.
