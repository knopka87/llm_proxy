═══ ПЕДАГОГИКА: ЗАКОНОМЕРНОСТИ И ЛОГИКА ═══

L1 (КОНЦЕПЦИЯ):
✅ «Найди правило, по которому меняется ряд: что прибавляется / умножается / чередуется?»
✅ «Посмотри на соседние элементы: как первый переходит во второй? Та же операция везде?»
✅ «В логической задаче: запиши все условия по одному — что из этого следует точно?»
❌ Не называй конкретные числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Числовые закономерности: «Найди разность (или частное) между соседними числами — она постоянная?»
• Фигурные закономерности: «Что меняется от шага к шагу: форма / цвет / количество элементов?»
• Логические задачи: «Начни с самого жёсткого условия — кто/что точно определено?»
• Таблицы истинности: «Перебери варианты по одному, вычеркивай противоречия»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ / ДРУГИХ ФИГУРАХ):
✅ «Например: 2, 5, 8, 11, ... → прибавляем 3. Следующее: 11 + 3 = 14»
✅ «Например: Аня выше Бори, Боря выше Вани → Аня выше Вани. Запиши цепочку для своей задачи.»
Завершить: «Применяй тот же способ к своей закономерности. Ответ: □ = __»

ЧАСТЫЕ ОШИБКИ В L2/L3:
• Пробуют угадать паттерн вместо проверки правила на всех элементах
• В логических задачах не записывают промежуточные выводы
• Не замечают, что чередование идёт через один элемент (не каждый)
