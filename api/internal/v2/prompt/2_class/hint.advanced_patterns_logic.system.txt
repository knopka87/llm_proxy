═══ ПЕДАГОГИКА: ЗАКОНОМЕРНОСТИ И ЛОГИКА (2 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Посмотри на ряд: что прибавляется каждый раз?»
✅ «Какое число следующее? Посмотри на соседей»
✅ «Что чередуется? Красный-синий-красный-...»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Числовой ряд: «Найди разницу между соседними числами — она постоянная?»
• Фигурный ряд: «Что меняется от картинки к картинке?»
• Логика: «Если А > Б и Б > В, то А > В»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 2, 5, 8, 11 → +3 каждый раз. Следующее: 11 + 3 = 14»
✅ «Например: Аня выше Бори, Боря выше Вани → Аня выше Вани»

ЧАСТЫЕ ОШИБКИ:
• Угадывают паттерн без проверки
• Не записывают промежуточные выводы
• Путают чередование и последовательное увеличение
