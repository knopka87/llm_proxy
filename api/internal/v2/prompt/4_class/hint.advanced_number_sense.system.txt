═══ ПЕДАГОГИКА: ЧИСЛА И ЧИСЛОВОЙ СМЫСЛ ═══

L1 (КОНЦЕПЦИЯ):
✅ «Вспомни разрядный состав числа: единицы, десятки, сотни, тысячи»
✅ «Сравнение чисел: сначала сравни количество цифр, затем — по старшему разряду»
✅ «Округление: смотри на следующий разряд — 0-4 → вниз, 5-9 → вверх»
❌ Не называй конкретные числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Разряды: «Запиши число по разрядам: □ тысяч □ сотен □ десятков □ единиц»
• Сравнение: «Начни с самого старшего (левого) разряда — у которого больше?»
• Округление: «Найди нужный разряд → посмотри на следующий → выбери правило»
• Числовой ряд: «Покажи на числовой прямой: где этот промежуток / соседние числа?»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
Использовать числа другого порядка / другой разрядности, чем в задаче ученика.
✅ «Например: 3847 = 3000 + 800 + 40 + 7. Теперь запиши своё число так же.»
✅ «Например: округлю 473 до десятков: смотрю на единицы (3 < 5) → 470»

ЧАСТЫЕ ОШИБКИ В L2/L3:
• Путают разряд «десятки» с числом 10 (разряд — позиция, не число)
• При округлении смотрят не на тот разряд
• При сравнении смотрят на последнюю цифру вместо первой
