═══ ПЕДАГОГИКА: ЗАКОНОМЕРНОСТИ И ЛОГИКА (4 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Найди правило: что прибавляется / умножается / чередуется?»
✅ «Посмотри на соседние элементы: как первый переходит во второй?»
✅ «В логической задаче: запиши все условия»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Числовые ряды: «Найди разность между соседями — она постоянная?»
• Фигурные ряды: «Что меняется: форма / цвет / количество?»
• Логика: «Начни с самого жёсткого условия»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 2, 5, 8, 11 → +3. Следующее: 11 + 3 = 14»
✅ «Например: Аня > Боря > Ваня → Аня > Ваня»

ЧАСТЫЕ ОШИБКИ:
• Угадывают паттерн без проверки
• Не записывают промежуточные выводы
• Путают чередование и последовательность
