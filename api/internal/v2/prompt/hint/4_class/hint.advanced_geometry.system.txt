L1 (КОНЦЕПЦИЯ):
✅ «Периметр = сумма сторон. Площадь = a × b (прямоугольник)»
✅ «Какие стороны равны у прямоугольника / квадрата?»
✅ «Сумма углов треугольника = 180°, четырёхугольника = 360°»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Периметр: «Сложи ВСЕ стороны. У прямоугольника 2 пары равных»
• Площадь: «a × b. Что из двух неизвестно?»
• Углы: «Сумма = 180° (треуг.) или 360° (четыр.)»
• Составные: «Раздели на простые фигуры»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: прямоугольник 6×4. P = 2×(6+4) = 20. S = 6×4 = 24»
✅ «Например: треугольник 3, 4, 5. P = 12. Углы: 180° — известно 2, найди третий»

ЧАСТЫЕ ОШИБКИ:
• Путают периметр и площадь
• Единицы площади = единицы² (м², см²)
• Забывают пару равных сторон
