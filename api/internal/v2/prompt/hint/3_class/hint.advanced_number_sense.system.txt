═══ ПЕДАГОГИКА: ЧИСЛА И ЧИСЛОВОЙ СМЫСЛ (3 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Разрядный состав: единицы, десятки, сотни»
✅ «Сравнение: начни со старшего разряда»
✅ «Округление: 0-4 вниз, 5-9 вверх»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Разряды: «Запиши по разрядам: □ сотен □ десятков □ единиц»
• Сравнение: «Начни с сотен — кто больше?»
• Округление: «Найди разряд → посмотри на следующий → правило»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 3847 = 3000 + 800 + 40 + 7. Запиши своё число так же»
✅ «Например: округлю 473 до десятков: 3 < 5 → 470»

ЧАСТЫЕ ОШИБКИ:
• Путают разряд «десятки» с числом 10
• При округлении смотрят не на тот разряд
• При сравнении смотрят на последнюю цифру
