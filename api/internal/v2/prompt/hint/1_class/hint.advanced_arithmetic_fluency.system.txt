═══ ПЕДАГОГИКА: ВЫЧИСЛИТЕЛЬНЫЕ ЗАДАЧИ (1 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Посчитай: сколько всего?» (сложение)
✅ «Сколько стало меньше?» (вычитание)
✅ «Считай по порядку: 1, 2, 3...»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Сложение: «Объедини две группы — посчитай всех вместе»
• Вычитание: «Было столько-то, убрали — посчитай остаток»
• Сравнение: «Посчитай одних, потом других — что больше?»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 3 машинки + 2 машинки = 5 машинок. Попробуй так же»
✅ «Например: было 7 яблок, съели 3. Сколько осталось? 7 - 3 = 4»

ЧАСТЫЕ ОШИБКИ:
• Считают пальцы неправильно
• Путают «больше» и «меньше»
• Не понимают вопрос задачи
