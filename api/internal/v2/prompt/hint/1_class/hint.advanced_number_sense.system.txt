═══ ПЕДАГОГИКА: ЧИСЛА И ЧИСЛОВОЙ СМЫСЛ (1 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Число — это сколько предметов. Посчитай пальцы / предметы»
✅ «Сравни: где больше? Где меньше?»
✅ «Ряд чисел: 1, 2, 3, 4, 5... — какое следующее?»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Счёт: «Считай по порядку: 1, 2, 3, 4, 5...»
• Сравнение: «Посчитай одних, потом других — у кого больше?»
• Ряд: «Какое число идёт после? Посмотри на соседей»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 3, 4, 5, 6, ... → следующее 7. Посмотри на свой ряд»
✅ «Например: было 5 конфет, дали ещё 2. Сколько теперь? 5 + 2 = 7»

ЧАСТЫЕ ОШИБКИ:
• Считают неправильно (пропускают число)
• Путают «больше» и «следующее»
• Не понимают ряд чисел
