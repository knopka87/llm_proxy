═══ ПЕДАГОГИКА: ЕДИНИЦЫ ИЗМЕРЕНИЯ (1 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Время: 1 час = 60 минут. Утро, день, вечер, ночь»
✅ «Длина: длинный — короткий. Большой — маленький»
✅ «Вес: тяжёлый — лёгкий»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Время: «Час — это когда стрелка делает полный круг. Минута — маленькая стрелка на 1»
• Длина: «Сантиметр — маленький кусочек. Метр — длина палки»
• Вес: «Килограмм — сколько весит пакет муки»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 2 часа = 120 минут. Посчитай: 1 час = 60 мин, 2 часа = 60 + 60 = 120»
✅ «Например: 3 метра + 2 метра = 5 метров. Применяй к своим числам»

ЧАСТЫЕ ОШИБКИ:
• Путают часы и минуты
• Не знают сколько минут в часе
• Сравнивают без единиц
