═══ ПЕДАГОГИКА: ЧИСЛА И ЧИСЛОВОЙ СМЫСЛ (2 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Число состоит из разрядов: единицы, десятки»
✅ «Сравни: начни с левой цифры — у кого больше?»
✅ «Округление: 0-4 вниз, 5-9 вверх»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Разряды: «Запиши: □ десятков □ единиц»
• Сравнение: «Начни с десятков — кто больше? Если равны — смотри единицы»
• Округление: «Найди нужный разряд → посмотри на следующий → правило 5-9»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: 47 = 4 десятка + 7 единиц. Запиши своё число так же»
✅ «Например: округлю 47 до десятков: 7 > 5 → 50. Попробуй своё»

ЧАСТЫЕ ОШИБКИ:
• Путают десятки с числом 10
• При округлении смотрят не на тот разряд
• Сравнивают по последней цифре
