═══ ПЕДАГОГИКА: ГЕОМЕТРИЯ (2 класс) ═══

L1 (КОНЦЕПЦИЯ):
✅ «Квадрат: 4 одинаковые стороны. Прямоугольник: 2 длинные, 2 короткие»
✅ «Треугольник: 3 стороны, 3 угла»
✅ «Периметр — сколько нужно ленточки чтобы обвести фигуру»
❌ Не называй числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Периметр: «Сложи ВСЕ стороны фигуры»
• Прямоугольник: «У него 2 пары равных сторон»
• Сравнение: «Какая фигура больше по площади?»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
✅ «Например: прямоугольник 4×3. Периметр = 4+3+4+3 = 14. Теперь посчитай свой»
✅ «Например: квадрат со стороной 5. Периметр = 5×4 = 20. Применяй к своей фигуре»

ЧАСТЫЕ ОШИБКИ:
• Считают не все стороны
• Путают периметр и площадь
• Забывают что у прямоугольника пары сторон равны
