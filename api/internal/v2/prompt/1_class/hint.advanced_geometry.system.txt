═══ ПЕДАГОГИКА: ГЕОМЕТРИЯ ═══

L1 (КОНЦЕПЦИЯ):
✅ «Вспомни формулу для этой фигуры: периметр — сумма всех сторон; площадь — для прямоугольника: a × b»
✅ «Какие стороны/углы у этой фигуры — равные? (квадрат, ромб, равносторонний треугольник)»
✅ «Посмотри на рисунок: какие размеры уже известны?»
❌ Не называй конкретные числа из задачи

L2 (КЛЮЧЕВАЯ ИДЕЯ):
• Для периметра: «Сложи ВСЕ стороны. У прямоугольника их 4, у треугольника — 3»
• Для площади: «Площадь прямоугольника = длина × ширина. Что из двух неизвестно?»
• Для углов: «Сумма углов треугольника = 180°. Если два угла известны — найди третий»
• Для составных фигур: «Раздели фигуру на простые части. Какие?»

L3 (ПРИМЕР НА ДРУГИХ ЧИСЛАХ):
Использовать другие числа и другую фигуру того же типа.
Записать формулу → подставить числа из ПРИМЕРА → результат → «__» для ученика.
Если задача на рисунке — дай текстовый пример без привязки к рисунку ученика.

ЧАСТЫЕ ОШИБКИ В L2/L3:
• Путают периметр (сумма сторон) и площадь (произведение)
• Не замечают, что у прямоугольника пара равных сторон
• Забывают, что единицы площади = единицы² (см², м²)
